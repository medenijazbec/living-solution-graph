# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful, constructive, and specific.
- Welcome different experience levels and viewpoints.
- Focus criticism on ideas and code, not people.
- Accept responsibility, apologize when appropriate, and learn from mistakes.
- Protect private information and respect project security processes.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, trolling, sexualized attention, publishing private information, or conduct that would reasonably be considered inappropriate in a professional setting is not acceptable.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this Code of Conduct. Serious or repeated violations may result in a temporary or permanent ban.

Report conduct concerns privately through the repository owner's GitHub profile or a private security advisory when confidentiality is necessary. Maintainers will respect the privacy and safety of reporters.
