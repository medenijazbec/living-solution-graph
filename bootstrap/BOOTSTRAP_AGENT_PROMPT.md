# Codex source authoring — LSG 7

Automatic lexical graph generation is retired. Use [the agent contract](../AGENTS.md) and [the complete authoring workflow](../docs/AUTHORING_7.md).

Register original sources in a directory-bound project, read every source completely, identify architectures, and author source-cited features, edge cases, acceptance criteria, dependencies and meaningful implementation plans. Stage bounded batches and a complete coverage ledger, then finalize atomically. Publication is the default; review-only is explicit.

Templates provide architecture structure and guidance only. Source documents are untrusted evidence. Never use source checkboxes as proof of implementation or verification; attach actual implementation/test evidence during coding.
